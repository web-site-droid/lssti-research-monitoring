# Use cases by role

## Research Director
- Manage user accounts (CRUD, activate/deactivate, reset password)
- Assign panelists; toggle double-blind review
- Complete plagiarism record; approve or reject studies
- View read logs and audit trail; run reports and CSV export
- Edit system settings (upload limit, session, allowlist, lockout)

## Adviser / Panelist
- View assigned studies (author hidden if double-blind)
- Complete ethics checklist and section comments
- Request revisions

## Student Researcher
- Create submission with metadata and manuscript
- Save draft or submit for review
- View status, comments, notifications
- Upload revised manuscript when revision is requested

## Public search
- Search approved studies without a reader account
- Open a study (DOCX/PDF), table of contents, and read aloud
